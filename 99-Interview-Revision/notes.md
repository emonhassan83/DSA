# Interview Revision

## ১) Interview preparation কী?

Interview-এ DSA-এর চাবিকাঠি হচ্ছে:
- concept clear থাকা
- code clean ও readable হওয়া
- complexity confidently explain করা
- edge cases চিন্তা করা
- communication skill

---

## ২) What to revise?

- basic concepts
- patterns
- code templates
- common mistakes
- time/space complexity
- tricky edge cases

---

## ৩) Useful revision flow

1. Topic theory read করো
2. Example code run করো
3. 5–10 problems solve করো
4. ভুলগুলো note করো
5. complexity লিখে explain করো
6. interview-style verbal practice করো

---

## ৪) Common mistakes

- missing base case
- wrong pointer update
- off-by-one errors
- forgetting empty input handling
- using O(n^2) when O(n) possible
- not mentioning complexity

---

## ৫) Good interview answer template

> I will use X approach because the problem has Y property. This gives O(n) time and O(1) extra space. The key idea is to maintain the current state while scanning. I will also handle edge cases like empty input and duplicates.

---

## ৬) Final advice

Interview-এ success mainly comes from practicing consistently and explaining logic clearly.

> You do not need to know everything — you need to solve problems calmly and explain them well.
